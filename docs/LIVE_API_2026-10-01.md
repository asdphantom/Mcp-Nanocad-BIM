## Fixes found in the host

- Slab and dome/loft/sweep factories compute XY base points. Requested Z now
  adds an offset instead of resetting XY to zero.
- Roof slope factory ignores baseline Z for entity placement. Apply Z once to
  its factory-computed base point, matching the SDK sample.
- CoordinateGridRef getters require write-open access in SDK 26. Listing
  upgrades within a transaction that is rolled back, without committing changes.
  Individual unreadable grids report an error rather than hiding all rows.
- Removed the executor's space command to a cached document from the HTTP
  thread. A space can repeat a command and the document may have been closed.
  Reused the existing UI timer, added reentrancy/expired-action guards, refreshed
  the document on the CAD thread and propagated action exceptions.
- Initial reopening caused an nCadS/coreclr access violation. After these
  corrections, close/open with the API loaded and native readback passed.
